# 🌾 GrainChain Landing Page MVP

An animated, responsive landing page that tells a compelling story about the grain post-harvest loss (PHL) crisis in Africa and how GrainChain provides a powerful solution.

---

## 🚀 Purpose

This is the **Phase 1 MVP** of the GrainChain platform. It's designed to:

- Raise awareness about post-harvest losses.
- Visually communicate the problem → solution journey.
- Include an interactive **PHL Estimator** to calculate potential savings.
- Serve as a foundation for future full-stack development (dashboard, user system, dApp, etc.).

---

## 🎯 Key Features

- Fully animated storytelling-based landing page (GSAP / Framer Motion)
- Mobile-first & responsive design
- Post-Harvest Loss Estimator tool
- Modular structure for scalability
- Lightweight and high-performance MVP

---

## 🛠️ Tech Stack

- **HTML**, **CSS** (refactor to TailwindCSS later)
- **JavaScript** (Vanilla JS for logic)
- **GSAP** (ScrollTrigger, Timeline)
- **Framer Motion** (future React version)
- **Git & GitHub** for version control
